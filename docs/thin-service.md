# TradingAgents local thin service

Start from this repository with the existing Python environment:

```powershell
python -m tradingagents.service --host 127.0.0.1 --port 8002 --data-dir C:\private\tradingagents-service
```

The service only binds to loopback. It reads provider settings and credentials from the existing TradingAgents environment/configuration, never from an HTTP request. Set the keys required by **both** effective quick and deep model providers before submitting paid work. Missing or unknown provider configuration returns `PROVIDER_NOT_CONFIGURED` (503) before accepting a run. Local keyless providers such as Ollama remain supported; the generic OpenAI-compatible provider also needs a configured server URL. No real Gemini call is part of offline verification.

Submit `POST /analysis` with `ticker` and `tradeDate`, or `POST /backtests` with `tickers`, `startDate`, and `endDate`. Optional request fields match the shared OpenAPI contract. The service returns a pending run (202) only after SQLite commits it. Poll `GET /runs/{runId}` or `GET /backtests/{backtestId}`. Read the allowlisted native narrative projection with `GET /runs/{runId}/report` after completion; pending and failed reports return 409. The published `/api/v1/analysis`, `/api/v1/analysis/{runId}`, `/api/v1/backtest`, and `/api/v1/backtest/{backtestId}` routes are aliases; `/api/v1/health` reports process readiness. Every error has the legacy `error/message/statusCode` fields plus `code/requestId/retryable`.

SQLite stores accepted requests, status, partial progress, final results, and report sections under `--data-dir`. An OS lock admits one service owner per data directory before restart recovery, including when the instances use different ports. A second instance exits without changing the active owner's runs. One dispatcher launches one child process at a time. Restart marks running work `RUN_INTERRUPTED`; it leaves unstarted pending work queued. A timed-out or stopped child is killed and reaped before another begins. No paid run is replayed automatically after interruption. Repeat POST creates a new run; clients should not automatically retry mutations. A random claim token fences late completion and progress from an interrupted worker.

The default queue holds 16 pending jobs, bodies are capped at 65,536 bytes, backtest grids at 256 unique ticker/date cells, and each child has a 900-second timeout. HTTP handling is capped at 16 concurrent connections with a five-second request read deadline, so an incomplete body cannot indefinitely block health or status polling. Excess connections close without acceptance. Adjust the queue, body and child timeout limits with `--max-pending`, `--max-body-bytes`, and `--worker-timeout` for local capacity; these are safeguards, not throughput guarantees. `/api/v1/health` returns 503 with a safe `DEPENDENCY_UNAVAILABLE` error if its dispatcher is absent, dead or stopping; healthy response remains `200 {"status":"ok","framework":"TradingAgents"}`. Browser mutations accept only this service's loopback origin; place dashboard calls behind same-origin routes. The service offers no public binding, arbitrary file download, caller-selected URLs, or credential/configuration parameters.

For backtests, `cellsAttempted` counts cells whose native run began; `cellsRun` counts verified completed cells and stays zero during execution until the native result returns. `cellsSkipped` comes from the native result. `summary.resolved`, `pending`, `unscored`, and `byRating` reflect native `summarize()`. Pending outcomes have not settled and are not empirical wins or losses. A cell or settlement failure yields `BACKTEST_PARTIAL_FAILURE` with truthful partial counts; the opt-in quota stop prevents later paid cells/settlements. This engine does not compute portfolio fills, return, drawdown, or aggregate performance metrics, so those optional fields are omitted.

Analysis `researchDepth` selects 1, 3, or 5 debate and risk rounds for quick, standard, or deep. Explicit `TRADINGAGENTS_MAX_DEBATE_ROUNDS` and `TRADINGAGENTS_MAX_RISK_ROUNDS` settings win, as in the CLI. `portfolio.asOf` is preserved as metadata in analysis responses; native `PortfolioContext` receives only positions, cash, and currency and does not value that book as of the timestamp.

`GET /assets/search?q=...` looks up at most eight supported equity, ETF, or USD-quoted crypto assets from Yahoo Finance quotes. The trimmed query must be 1–80 characters; missing quote metadata stays absent. `GET /market-data/{assetType}/{symbol}?startDate=YYYY-MM-DD&endDate=YYYY-MM-DD` returns native adjusted daily prices over at most 366 days. Crypto requires an explicit USD pair such as `BTC-USD`; bare and USDT/USDC symbols are rejected. The stock route rejects quoted crypto, futures, forex and index symbols before a vendor read while keeping ambiguous bare equity tickers and native stock-market code normalization. Bars use calendar trading dates, omit missing optional cells and gaps, and conservatively exclude bars on or after the earlier of the service's local or UTC current date. This avoids presenting an ongoing UTC vendor day as historical when the local calendar is already tomorrow. Treat these as historical adjusted observations, not fills, execution prices, portfolio returns, or confirmed current-session closes. Empty search results are real empty results; unavailable or stale Yahoo data returns a safe 503 error.

At most two market reads run in separate killable child processes. A third concurrent read receives 429 `READ_BUSY`; a stalled read is terminated at the 45-second absolute deadline and receives 504 `DEPENDENCY_TIMEOUT`. The HTTP request read deadline remains five seconds and 16 handlers remain the total connection bound. Child results are atomically written under private `--data-dir/read-state`, capped at 1 MiB, and removed after the child exits. Native OHLCV and yfinance metadata caches stay under the service data directory. A disconnected client does not cancel an already admitted read immediately; the service still enforces its deadline and shutdown cleanup. Market reads never create paid jobs.
